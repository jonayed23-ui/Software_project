# Software_project
 Mentors Diary 📘

Mentors Diary is a software project designed to help mentors manage, track, and organize student activities efficiently. The system provides a structured platform where mentors can record meetings, monitor student progress, and maintain important notes in one place.

🎯 Objective
The main goal of this project is to simplify communication and record-keeping between mentors and students through a digital platform.

🚀 Key Features
- Mentor profile management
- Student information tracking
- Meeting record system
- Progress monitoring
- Organized digital diary system

 📄 Project Documentation
The complete project report is available in the repository as a PDF file.

📌 Purpose
This project was developed as part of academic coursework to improve practical knowledge in software development and system design.
